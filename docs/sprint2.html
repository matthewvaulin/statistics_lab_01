0.1.Задача спринта

В спринте 1 исследованы три величины:

  1. $X_1=e_{ij}^{\max}$ — максимальный пьезоэлектрический коэффициент, Кл/м²; выбранная модель — распределение Ломакса, $\hat\alpha\approx1.568$, $\hat\lambda\approx0.473$ Кл/м² (спринт 1, раздел 1.2.3).
  2. $X_2=n$ — показатель преломления; выбранная модель — GEV, параметры из спринта 1: $c\approx-0.281$, $\hat\mu\approx1.872$, $\hat\sigma\approx0.513$, в параметризации SciPy $c=-\xi$ (спринт 1, раздел 2.2.3).
  3. $X_3=V/N$ — объём на атом, Å³/атом; выбранная модель — сдвинутое логнормальное распределение, $s\approx0.535$, $\hat\theta\approx3.902$ Å³/атом, $e^{\mu_Y}\approx12.814$ Å³/атом.

Цель спринта: построить генераторы для всех трёх распределений, подробно обосновать два разных алгоритма для $X_1$, проверить генераторы тестами, сравнить моделируемые выборки с исходными данными и обсудить ограничения выбранных моделей.

Генератор (датчик) случайных чисел — это функция, которая выдаёт числа, распределённые по заданному закону. Он нужен, когда реальных данных мало, а для расчётов и проверок требуется много значений с теми же свойствами. Все четыре генератора работы получают на вход равномерные случайные числа из стандартного генератора NumPy и преобразуют их в нужное распределение.

0.5.Оценивание параметров

Параметры ниже оцениваются методом максимального правдоподобия (MLE). Для Ломакса при фиксированном loc=0 логарифм правдоподобия:

$$\ell(\alpha,\lambda)=m\ln\alpha-m\ln\lambda-(\alpha+1)\sum_{i=1}^m\ln(1+x_i/\lambda).\tag{0.1}$$

Оценки — аргументы максимума этой функции. Для GEV и сдвинутой логнормальной модели используем численную MLE-оптимизацию SciPy. Сдвиг логнормального распределения может быть слабо идентифицируемым на конечной выборке, поэтому оценку loc нужно интерпретировать осторожно.

0.6.Как проверяются генераторы

Автотесты проверяют контракт функций (размерность, конечность, носитель), воспроизводимость по seed, обработку ошибочных аргументов и базовые статистические свойства стандартного нормального генератора. Статистические тесты не должны проходить «всегда»: при корректной модели вероятность случайного отклонения на уровне значимости 0.05 составляет около 5 %. Поэтому тесты не зашиваем как жёсткое условие p > 0.05 для единственной случайной реализации; вместо этого показываем статистики и p-value.

Для алгоритмов, основанных на преобразованиях, полезно проверить промежуточные стандартные величины. Для генератора Ломакса по обратной функции величина $F(X)$ должна быть равномерной на $(0,1)$; для гамма-смеси PIT также должно быть равномерным. Для метода Бокса–Мюллера проверяем нормальность $Z$ графически и по моментам. При больших объёмах выборки формальные тесты очень чувствительны к малым отклонениям, поэтому интерпретируем их вместе с графиками.

В каждом разделе о генераторе проверки идут в одном порядке: таблица автотестов контракта, гистограмма PIT и критерий КС для PIT. Сводка по всем генераторам — в табл. 6.1.

1.random 01 — Ломакс, метод обратной функции

1.1.Description

Что генерируем. Значения $X_1$ — модельный пьезокоэффициент $e_{ij}^{\max}$ в Кл/м². В спринте 1 для него выбрано распределение Ломакса: большинство значений малы, но изредка встречаются очень большие.

Идея метода. Функция распределения $F(x)$ каждому значению сопоставляет число от 0 до 1. Идём в обратную сторону: берём случайное число $U$ от 0 до 1 и находим то значение $x$, для которого $F(x)=U$. Для Ломакса обратная функция выписывается явно, поэтому генератор занимает одну строку.

1.2.math desc

Для $x\geq0$, $\alpha>0$, $\lambda>0$:

$$f(x)=\frac{\alpha}{\lambda}\left(1+\frac{x}{\lambda}\right)^{-\alpha-1},\qquad F(x)=1-\left(1+\frac{x}{\lambda}\right)^{-\alpha}.\tag{1.1}$$

Обратная функция находится непосредственно из $u=F(x)$:

$$Q(u)=\lambda\left((1-u)^{-1/\alpha}-1\right),\quad 0<u<1.\tag{1.2}$$

Если $U\sim U(0,1)$, то $P(Q(U)\leq x)=P(U\leq F(x))=F(x)$, следовательно, $Q(U)$ имеет распределение Ломакса.

Моменты и хвост. $E[X]=\lambda/(\alpha-1)$ при $\alpha>1$; $\operatorname{Var}[X]=\lambda^2\alpha/[(\alpha-1)^2(\alpha-2)]$ при $\alpha>2$. Момент порядка $k$ существует только при $k<\alpha$. Для оценки из спринта 1 $\hat\alpha\approx1.568$: математическое ожидание конечно, дисперсия бесконечна. Поэтому среднее существует, но чувствительно к экстремальным наблюдениям; медиана и квантили устойчивее. Хвост степенной: $P(X>x)=(1+x/\lambda)^{-\alpha}\sim (x/\lambda)^{-\alpha}$.

Ломакс — частный случай обобщённого распределения Парето (GPD) при положительном параметре формы $\xi=1/\alpha$ и масштабе $\beta=\lambda/\alpha$ в стандартной записи GPD. GPD возникает как предельная модель превышений над высоким порогом в теореме Пикандса–Балкема–де Хаана. Здесь это мотивация для тяжёлого хвоста, а не доказательство того, что исходные материалы являются независимыми превышениями порога.

Алгоритм. Из равномерной последовательности $U_i$ вычисляем $X_i=Q(U_i)$ по формуле (1.2). Преимущество — одна равномерная величина на один результат, явная формула и простая проверка. Недостаток — преобразование содержит логарифм и экспоненту (в численно устойчивой форме log1p/expm1).

def lomax_inverse(n, alpha, scale, rng=None):
    """Lomax через обратную функцию распределения."""
    if not isinstance(n, (int, np.integer)) or n < 0:
        raise ValueError("n должно быть целым неотрицательным")
    if not np.isfinite(alpha) or alpha <= 0 or not np.isfinite(scale) or scale <= 0:
        raise ValueError("alpha и scale должны быть положительными конечными числами")
    rng = np.random.default_rng() if rng is None else rng
    u = rng.random(n)
    return scale * np.expm1(-np.log1p(-u) / alpha)

2.random 02 — Ломакс, гамма-экспоненциальная смесь

2.1.Description

Что генерируем. То же распределение Ломакса для $X_1=e_{ij}^{\max}$, Кл/м², но другим способом. Два независимых по устройству генератора одного закона можно сверить друг с другом.

Идея метода. Значение получается в два шага. Сначала случайно выбирается скорость убывания $T$ (из гамма-распределения), затем из экспоненциального распределения с этой скоростью берётся само значение. Когда $T$ случайно оказывается малым, экспоненциальное распределение растянуто и выдаёт большие значения: так возникает тяжёлый хвост.

2.2.math desc

Это альтернативная конструкция, не использующая обратную функцию Ломакса. Сначала генерируем $T\sim\mathrm{Gamma}(\alpha,\text{rate}=1)$, затем условно генерируем $X\mid T\sim\mathrm{Exp}(\text{rate}=T/\lambda)$.

Проверка плотности через интегрирование:

$$f(x)=\int_0^\infty \frac{t}{\lambda}e^{-tx/\lambda} \frac{t^{\alpha-1}e^{-t}}{\Gamma(\alpha)}dt =\frac{\alpha}{\lambda}(1+x/\lambda)^{-\alpha-1}.\tag{2.1}$$

Последнее равенство следует из интеграла Гамма-функции $\int_0^\infty t^\alpha e^{-bt}dt=\Gamma(\alpha+1)b^{-\alpha-1}$ и $\Gamma(\alpha+1)=\alpha\Gamma(\alpha)$. Значит, маргинальное распределение $X$ в точности Ломакс. Метод требует двух случайных шагов и может быть медленнее, зато демонстрирует представление тяжёлохвостого закона как смеси экспоненциальных распределений.

Плотность в правой части (2.1) совпадает с плотностью Ломакса (1.1).

    """Lomax как смесь экспоненциальных: T ~ Gamma(alpha, rate=1), X | T ~ Exp(rate=T/scale)."""

3.random 03 — GEV, квантильное преобразование

3.1.Description

Что генерируем. Значения $X_2$ — модельный показатель преломления $n$ (безразмерный). В спринте 1 для него разобрано обобщённое распределение экстремальных значений (GEV). Там же показано, что согласие GEV с данными отвергается критерием; генератор строится с этой оговоркой.

Идея метода. Та же, что в разделе 1: равномерное число $U$ подставляется в квантильную функцию. Отличие в том, что квантиль берётся из готовой реализации SciPy.

3.2.math desc

В параметризации экстремального значения:

$$F(x)=\exp\left[-\left(1+\xi\frac{x-\mu}{\sigma}\right)^{-1/\xi}\right],\tag{3.1}$$

где $\sigma>0$ и $1+\xi(x-\mu)/\sigma>0$. При $\xi\to0$ получаем распределение Гумбеля. Квантиль:

$$Q(u)=\mu+\frac{\sigma}{\xi}\left[(-\ln u)^{-\xi}-1\right],\quad \xi\ne0,\tag{3.2}$$

а при $\xi=0$: $Q(u)=\mu-\sigma\ln(-\ln u)$. В scipy.stats.genextreme параметр c имеет противоположный знак: $c=-\xi$. Поскольку в спринте 1 $c\approx-0.281$, оценка $\xi\approx0.281$ соответствует тяжёлому правому хвосту: при $\xi>0$ у GEV верхняя граница отсутствует, нижняя конечна. Моменты: при $\xi<1$ среднее существует, $$E[X]=\mu+\frac{\sigma}{\xi}\left[\Gamma(1-\xi)-1\right],\tag{3.3}$$ а при $\xi<1/2$ существует дисперсия $$\operatorname{Var}[X]=\frac{\sigma^2}{\xi^2}\left[\Gamma(1-2\xi)-\Gamma^2(1-\xi)\right].\tag{3.4}$$ В пределе $\xi\to0$ получаем среднее $\mu+\gamma\sigma$ и дисперсию $\pi^2\sigma^2/6$, где $\gamma$ — постоянная Эйлера. Для найденного $\hat\xi\approx0.281$ оба момента существуют.

Алгоритм. Используем аналитическую квантильную формулу GEV (3.2). Для численной устойчивости граничные равномерные значения ограничиваем машинным интервалом $(0,1)$. Параметризация согласована с SciPy: $\xi=-c$.

4.random 04 — сдвинутое логнормальное, метод Бокса–Мюллера

4.1.Description

Что генерируем. Значения $X_3$ — модельный объём на атом $V/N$ в Å³/атом. Модель — логнормальное распределение со сдвигом: логарифм величины (после вычитания сдвига) распределён нормально.

Идея метода. Сначала из пары равномерных чисел получаем нормальное число $Z$ методом Бокса–Мюллера, затем превращаем его в нужную величину: растягиваем, берём экспоненту и прибавляем сдвиг. В отличие от разделов 1 и 3, квантильная функция здесь не используется.

4.2.math desc

Пусть $X=\theta+\exp(Y)$, где $Y\sim N(\mu_Y,s^2)$. Тогда для $x>\theta$:

$$f(x)=\frac{1}{(x-\theta)s\sqrt{2\pi}}\exp\left[-\frac{(\ln(x-\theta)-\mu_Y)^2}{2s^2}\right],\tag{4.1}$$

$$F(x)=\Phi\left(\frac{\ln(x-\theta)-\mu_Y}{s}\right),\quad Q(u)=\theta+\exp(\mu_Y+s\Phi^{-1}(u)).\tag{4.2}$$

В SciPy shape=s, loc=theta, scale=exp(mu_Y). Логнормальность естественно появляется при мультипликативном формировании величины: произведение множества положительных факторов после логарифмирования превращается в сумму. Сдвиг $\theta$ задаёт нижнюю границу модели; он является параметром аппроксимации, а не автоматически установленным физическим минимальным объёмом атома.

Алгоритм. Метод Бокса–Мюллера строит пару независимых стандартных нормальных величин из двух независимых $U_1,U_2\sim U(0,1)$:

$$Z_1=\sqrt{-2\ln U_1}\cos(2\pi U_2),\quad Z_2=\sqrt{-2\ln U_1}\sin(2\pi U_2).\tag{4.3}$$

Затем $Y=\mu_Y+sZ$ и $X=\theta+e^Y$. Это даёт сдвинутую логнормальную модель. В отличие от GEV, где используется квантильное преобразование, здесь нормальная величина генерируется отдельным алгоритмом.

def standard_normal_box_muller(n, rng=None):
    """n независимых значений N(0,1) методом Бокса–Мюллера."""
    if n < 0 or int(n) != n:
        raise ValueError("n должно быть целым неотрицательным")
    rng = np.random.default_rng() if rng is None else rng
    pairs = (int(n) + 1) // 2
    u1 = np.maximum(rng.random(pairs), np.finfo(float).tiny)
    u2 = rng.random(pairs)
    radius = np.sqrt(-2.0 * np.log(u1))
    z = np.empty(2 * pairs)
    z[0::2] = radius * np.cos(2 * np.pi * u2)
    z[1::2] = radius * np.sin(2 * np.pi * u2)
    return z[:int(n)]

def shifted_lognormal_box_muller(n, shape, loc, scale, rng=None):
    """X = loc + exp(Y), Y ~ N(log(scale), shape^2)."""
    if shape <= 0 or scale <= 0 or not np.isfinite(shape + loc + scale):
        raise ValueError("shape и scale должны быть положительными; параметры конечными")
    rng = np.random.default_rng() if rng is None else rng
    z = standard_normal_box_muller(n, rng)
    return loc + np.exp(np.log(scale) + shape * z)

5.2.Адекватность моделей на исходных данных

Проверка Колмогорова–Смирнова с параметрами, оценёнными на той же выборке, имеет некорректный стандартный нулевой закон. Поэтому используем параметрический бутстреп: генерируем выборки из подогнанной модели, на каждой повторно оцениваем параметры и считаем КС-статистику. В SciPy это реализовано в stats.goodness_of_fit. Достаточно 199 повторов для учебной диагностики; для более точной оценки p-value число повторов следует увеличить (например, до 999 или 4999).

5.3.Состоятельность оценок и эксперимент со сходимостью

Состоятельность — свойство последовательности оценок: при увеличении объёма выборки оценка сходится по вероятности к истинному параметру. Здесь генеральная совокупность в эксперименте — конечный эмпирический массив из 941 значения $X_1$. Для каждого объёма $m$ много раз берём простую случайную выборку без возвращения и наблюдаем ошибку оценок относительно параметров, рассчитанных по всему массиву. Это демонстрация сходимости к характеристикам конечной эмпирической совокупности, а не строгое доказательство асимптотической состоятельности для неизвестной бесконечной популяции.

Дополнительно показываем параметр $\alpha$ подогнанного распределения Ломакса. При малых выборках MLE может быть неустойчивой или не иметь конечного максимума; неудачные подгонки отмечаем отдельно, а не маскируем произвольным отсечением. Дисперсию Ломакса с $\alpha<2$ не используем как теоретическую цель, поскольку она бесконечна.

Тот же эксперимент для среднего, медианы и дисперсии описан в спринте 1, раздел 1.3.2.
