## Как открыть HTML-версию

GitHub показывает `.html` из репозитория как исходный код, а не как страницу. Есть два способа:

1. **GitHub Pages.** В репозитории: Settings → Pages → Source: «Deploy from a branch» → ветка с папкой `docs`, папка `/docs` → Save. Через минуту отчёт откроется по ссылке в начале этого файла.
2. **Скачать.** Сохранить файл из папки [docs](docs) и открыть двойным кликом. Картинки и стили встроены в файл. Интернет нужен только для формул: MathJax подгружается с cdnjs.

В HTML код скрыт и раскрывается кнопкой «Показать код».

## Запуск

Нужен Python 3.12 или новее. Команды выполняются из папки `piezo_project`:

```sh
python -m pip install -r requirements.txt
jupyter notebook
```

Ноутбук спринта 1 считается около четырёх минут, спринта 2 — около минуты.

Проверки:

```sh
python check_project.py
python -m unittest test_generators -v
python tools/check_links.py
```

Пересборка HTML после изменения ноутбуков (ноутбуки не пересчитываются, берутся сохранённые выводы):

```sh
python tools/build_html.py
```

## Как читать результаты

Меньший AIC означает преимущество относительно проверенных кандидатов, но не доказанное согласие с данными. GEV для показателя преломления остаётся проверенной рабочей гипотезой и отвергается тестом согласия. Итоговая таблица показывает как исходные p-value, так и поправку Холма. Имитации с подвыборками описывают имеющийся конечный набор, а не доказывают представительность базы для всех материалов.
